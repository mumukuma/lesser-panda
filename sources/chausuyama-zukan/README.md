# 茶臼山動物園「動物情報バックナンバー」原文存檔

長野市茶臼山動物園舊官網 CMS 的年度動物情報存檔，原始位址為
`http://www.chausuyama.com/zukan/zukan/YYYY`。本資料夾按年存放**小熊貓相關段落的日文原文照抄**，
取得日 2026-07-29。

## ⚠️ 原始網址已失效（2026-07-29 確認）

官網已改版為扁平靜態站（`event.html`、`news/YYYY-MM-DD.html` 等結構），
舊 CMS 的 `/zukan/zukan/YYYY` 路徑**整批下架，瀏覽器開啟為 404**
（BiND Cloud「このURLは存在しません」）；`/zukan`、`/zukan/`、`/zukan/zukan/` 亦無索引頁。
新站上找不到這批 2003–2022 記述的任何替代頁面。

wiki 各條目的 `sources:` **仍保留原始位址作為 canonical 出處**（學術引用慣例：
記錄資料當初的正式發布位置），原文請以本資料夾為據。要線上覆核請走 Wayback Machine：

```
https://web.archive.org/web/2018/http://www.chausuyama.com/zukan/zukan/2013
```

（timestamp 可省略成年份，會轉到最近的快照。）`tools/build_db.py` 的
`is_official_source` 會拆開 Wayback URL、改判內層 host，因此上面這種寫法
也會被正確認列為官方來源；`web.archive.org` 本身並未整域列入白名單。
