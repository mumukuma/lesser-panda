## 二、共通的一處錯誤：「出生動物園：西安動物園」不成立

四隻（唐唐・安安・渝渝，以及投稿沒寫但同理的）都填了 `出生動物園：西安動物園`。**三個來源沒有一個這麼說**：

- 《ズーしずおか》84 号（園方一手，已實開確認原文）：
  > 中国の西安市との**動物交換**により、ノガン2羽、キンケイ6羽とともにレッサーパンダ2頭が**寄贈**されたのが始まりです
- 〈でっきぶらし〉197 号：「中国の西安市**から来園した**ペア」
- ISB：`8019`／`8220` 的父母欄都是 `WILD`，生年是推定值 `~1978`／`~1980`，且 `8019` 的事件列**根本沒有 Capture 行**——ISB 自己也不知道他從哪來

→ 西安是**動物交換／贈與的來源地**，不是出生園。三隻都應寫 `birth_zoo: unknown`，敘述寫「經中國西安市動物交換來日」。
（附帶好處：`data/zoos.json` 不必為此新增「西安動物園」，省掉非日本園要補 `location_zh`／合成 ID 那一整套坑。）

渝渝那批的同行動物是ベンガルヤマネコ（豹貓），不是猛禽——兩批不同，敘述別混。

### ⚠️ szga PDF 的坑（值得記進 memory）
- 沙盒 proxy 對 `www.szga.jp` 回 **403**，`WebFetch` 抓得到檔但回「PDF is empty or contains no machine-readable text」
- 原因：**這份 PDF 是掃描件，9 頁全無文字層**（pdf.js `getTextContent()` 全 9 頁合計只有 107 字元）
- Chrome 內建 PDF viewer 的畫面**截圖抓不到**（只有側邊縮圖與工具列會進截圖）
- 可行解：在 `https://www.szga.jp/` 同源頁面用 `javascript_tool` → `import()` cdnjs 的 pdf.js → 同源 `fetch()` PDF → 渲染到 canvas → `replaceChildren` 換掉 DOM → 再 `screenshot`／`zoom` 讀。渲染會超過 CDP 45 秒回應上限而報 timeout，但**畫面其實已經畫出來了**，直接接著截圖即可
- 小熊貓那篇在**第 5 頁**
