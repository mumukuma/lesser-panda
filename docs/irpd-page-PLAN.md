## 2. 章節大綱

### 2.1 這是什麼日子

- **每年 9 月第三個週六**。2026＝**9/19**、2027＝9/18、2025＝9/20。
- **由 Red Panda Network 提倡**。日本園的官方頁講得比英文源頭還清楚，可直接引為佐證：仙台市八木山動物公園寫「レッサーパンダに関する環境教育や啓発活動を行う日にしようと、野生のレッサーパンダ生息域で保全活動を展開している Red Panda Network により提唱されました」。
- **首辦年份：留白**（2026-08-28 裁定）。二手來源常見「2010 年」，但 RPN 官網自己沒寫、National Today 等站的年表也沒有。依專案來源原則不抄二手站；**正文只寫「由 RPN 提倡」，不寫年份、也不對讀者顯示 🚧**（這是對外知識頁，不是條目）。日後若找到 RPN 官方或早期新聞稿佐證再補。

### 2.2 為什麼需要這個日子

- 現況：IUCN 瀕危（Endangered）、CITES 附錄 I（1995 生效）；野外成熟個體數 🚧 以 IUCN 頁面現值為準。
- 三大威脅：棲地破碎化、盜獵與非法貿易、犬瘟熱等疾病。
- **「知名度陷阱」是這頁的敘事核心**：小熊貓的可愛度極高、但保育關注度極低，名字還被大熊貓的名氣蓋掉——所以需要一個「刻意被指定的日子」。
- RPN 自己說這天最重要的目標之一是**青少年教育**，不是募款——這正好呼應日本園的做法（展示＋解說，而非募捐）。
- 站內串連：`/species/`（保育現況段）、`/stats/`、`/japan/`（日本族群逐年變化）。

### 2.3 日本動物園怎麼過這天（通則＋代表例）

**通則五類**（每一類都有官方頁佐證，寫成「常見做法」而非「今年活動」）：

1. **飼育員談話／解說會** — ガイド、トーク、どうぶつ教室
2. **特別餵食／行動展示** — おやつタイム、エンリッチメント
3. **保育啟蒙展示** — パネル展；把野生現況與 RPN 的工作搬進園內（有些園會展出當年出生個體的成長紀錄）
4. **限定周邊與聯名餐點** — グッズ特設コーナー、フォトキーホルダー、コラボメニュー
5. **保育募金／認養** — 部分園有，非通例

**時間慣例（值得單獨寫一句）**：日本園多半**不辦在當天**，而是前後一到兩週的檔期。例：よこはま動物園ズーラシア 2026 年是 **9/2–9/28** 整個月的檔期。

**代表例清單（2026-08-28 定案：可增補的清單，目前 3 園）**

結構為「**園名＋站內園頁＋官方連結＋一句描述**」。日後維護者看到新的就丟連結進來補：

| 園 | zoos.json id | 為什麼選它 |
| --- | --- | --- |
| 仙台市八木山動物公園 | 45 | 官方頁把「這天由 Red Panda Network 提倡」的由來寫在活動說明前面 |
| よこはま動物園ズーラシア | 12 | 檔期最長（2026 為 9/2–9/28），五類活動全包 |

**候補（作者日後看到再補）**：野毛山動物園、埼玉県こども動物自然公園、神戸市立王子動物園、周南市徳山動物園、京都市動物園、大牟田市動物園、池田動物園、平川動物公園、浜松市動物園、ネオパークオキナワ。

**實作方式**：清單存成 `data/irpd-zoos.json`（或直接寫在 `Irpd.astro` 的常數陣列，首批兩園時後者更簡單），每筆 `{zoo: canonical, url: 官方連結, note_key: i18n key}`。

- 園名不必翻譯——`zooName()` 已依語系吐正確名稱；站內園頁連結由 `zoos.json` 的 slug 自動組。
- **只有「一句描述」需要五語**（`irpd_zoo_<slug>` 一組 key × 5）。`tools/check_i18n.py` 會擋 key 不齊，所以**每補一園＝補五份**；作者丟連結來時由 Claude 一併產四語譯句，作者只需校 zh-TW。
- ⚠️ 園名一律用 `data/zoos.json` 的 canonical；未登記的園要先加一筆再寫（`tools/resolve_zoo.py` 可核）。
- ⚠️ 官方活動頁**檔期結束後常改標題或下架**（已見「【イベントのみ終了】」「※終了しました」）。首選連園方官網的 IRPD 常設／最新活動頁，若只有年度頁則把原文抄進正本備存，連結失效時可退回站內園頁。

⚠️ **維護成本控制（這是選「通則＋代表例」的重點）**：代表例寫成「這些園歷年都會辦，內容大致是 X」，**不寫「2026 年 9 月 19 日辦 Y」**。凡是要提年份的地方，一律明寫「以 2026 年為例」，讓隔年讀起來仍是正確敘述而非過期資訊。每年只需微調，不必逐園重查。

### 2.4 Red Panda Network 是誰

- **2007 年成立**（官網 what-we-do 頁自述），從東尼泊爾起家；創辦人 Brian Williams。
  - 🚧 二手來源有「2005 年」說法（National Today），**以官網為準**，衝突照專案慣例記在備注。
- **方法論**：以社區為基礎的**地景層級**保育——不是圈一塊地趕人出去，而是讓當地社群成為守護者。這是它跟一般保育組織最不一樣的地方，值得寫足一段。
- **招牌方案**：
  - **Forest Guardians**（在地巡護員）— RPN 最有辨識度的招牌
  - **PIT Red Panda Protected Forest**（社區保護林）
  - 與社區林戶組織（Community Forest User Groups）合作的永續林業
- **規模數字**（引官網、標明取自何時；數字會變，寫成「官網稱」）：逾 100 萬英畝林地納入保育計畫、涵蓋尼泊爾約 50% 小熊貓分布、23 個分布郡中的 13 郡、逾 75 個社區林戶組織，並已延伸至不丹。
- **與圈養族群的接點**（把 2.3 和 2.4 縫起來的段落）：日本園的 IRPD 活動幾乎都引用 RPN 的說法——這天的意義正是**把野生端的處境帶到看得見圈養個體的人面前**。本站記錄的是圈養個體，野生端的工作由 RPN 這類組織承擔，兩邊是互補而非替代。
- **「想支持的話」小區塊（克制版）**：
  - 一小段、置於章節末，外連 RPN 官網的 Adopt／Donate／Forest Guardian 頁。
  - **明確聲明**：本站與 RPN 無隸屬或合作關係、不經手任何金流、不抽成，連結僅供參考。
  - 不做比較、不催促、不放捐款金額表。
